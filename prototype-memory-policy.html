    The first version deliberately chooses useful personality over exhaustive recall.

    Keep one direct, concrete, lasting self-claim. Never turn hearsay into participant identity.
    Keep one concrete, source-aware episode when it has clear future callback value.
    Derive one simple interaction pattern only after repeated addressed interactions.
    Retrieve at most the best relevant memory, and never force the LLM to use it.
    Allow intentional silence only when an interaction pattern makes ghosting a clear personality beat.
    Do not model running gags in the first version. Episodes can still support callbacks.
